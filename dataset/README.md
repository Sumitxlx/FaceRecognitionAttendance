# Dataset

This folder is used to store registered student face images.

The actual dataset is **not included** in this repository to protect privacy.

## Folder Structure

```text
dataset/
├── student_name/
│   ├── 0.jpg
│   ├── 1.jpg
│   ├── ...
│   └── 29.jpg
```

To use this project, create a folder for each student inside the `dataset` directory and add their face images.
